# PC-Toolkit

PC-Toolkit is a simple collection of Windows utilities designed to help users
diagnose their PC and understand their system configuration.

## Features

- Display basic PC information
- Check CPU and RAM usage
- Check available disk space
- Generate a simple system report
- Provide useful Windows diagnostics

## Goals

The goal of PC-Toolkit is to provide simple and accessible tools for Windows
users without requiring advanced technical knowledge.
